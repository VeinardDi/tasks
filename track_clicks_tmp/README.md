## Задача
Нужно разработать сервис, который будет считать количество уникальных пользователей, 
кликнувших в любую публикацию автора за календарные сутки.
Сутки считаем по времени сервера, с 0:00 предыдущего дня до 0:00 текущего.

- Каждый раз, когда кто-то кликает в публикацию, клиент отправляет запрос с id пользователя и автора.
- Когда мы собираем ленту рекомендаций для очередного пользователя - в наш сервис поступает запрос со списком авторов, 
для которых мы хотим посчитать метрику.

Для упрощения считаем, что сервис работает на одной машинке, необходимые данные помещаются в память.
